### Why This Works

**Before:**
- Ko-fi text limited, cuts off long URLs
- Can't paste URLs directly (gets mangled)
- Readers have to scroll and copy-paste
- Looks messy in Ko-fi description

**After:**
- Short, clean links: `shortl.ink/XXX`
- No character limit issues
- Clickable and shareable
- Professional appearance
- Click tracking to see which chapters are popular

## Adding More Chapters

As you add more chapters to RanobeVault:

1. Get the new chapter URL
2. Go to **Create Link** tab
3. Paste URL, add chapter title (e.g., "Ch 16")
4. Click **Create Short Link**
5. Copy the short code
6. Update Ko-fi

Or keep using **Bulk Import** if you're adding multiple at once.

## Link Management

### Viewing Your Links
Your dashboard automatically tracks:
- **Total Links**: 15+ (grows as you add)
- **Total Clicks**: See overall traffic
- **Individual Click Count**: See which chapters are most popular

This gives you insights into reader engagement!

### Copying Links
For each link in your dashboard:
- **Copy** - Full short URL (`shortl.ink/aBc123`)
- **Copy Code** - Just the code (`aBc123`) if you use your own domain
- **Delete** - Remove old or unused links

### Link Persistence
Once created, links are **permanent**. Even if you delete from your dashboard, the short code works forever (unless explicitly deleted).

---

## Privacy Note

- Only you can see your full original URLs
- The short links are public (anyone with the code can access)
- Click counts are stored on your server only
- No tracking of who clicks, just how many

Perfect for Ko-fi where you want to share chapters but don't need invasive analytics.

## Quick Tips for Ko-fi

1. **Use a custom domain** - looks more professional
   - `chapters.yourdomain.com/aBc123` looks better than `shortl.ink/aBc123`

2. **Update your Ko-fi description once**
   - Add all links upfront
   - New chapters can be added individually

3. **Include link in chapters post**
   - Ko-fi posts have more character limit
   - Include short link in your chapter post content too

4. **Test your links**
   - Click each one before sending to Ko-fi
   - Verify unlock tokens work (they should!)

5. **Backup your links**
   - Screenshot or export your link dashboard
   - If something goes wrong, you still have the short codes

## Need Help?

**Q: A link doesn't work**
- Check the original RanobeVault URL still works
- If RanobeVault URL is down, the short link will also be down
- Short links are just redirects, not mirrors

**Q: Want to change a chapter title**
- Create a new link with the updated title
- Delete the old one
- Update Ko-fi with the new short code

**Q: Can I share short links elsewhere?**
- Yes! Twitter, Reddit, Discord, etc.
- They work anywhere - not just Ko-fi
- No character limit issues anywhere

**Q: What if I want to switch domains?**
- Update the `API_URL` in the dashboard
- All links stay the same, just different domain
- Old domain links break (redirect won't work)
