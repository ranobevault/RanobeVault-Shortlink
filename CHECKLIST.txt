  Click: "Import Git Repository"

When done, go to: Settings → Environment Variables

ADD 3 VARIABLES:

Variable 1:
  Name: SUPABASE_URL
  Value: https://cfdehwctigvtvijndlns.supabase.co
  (Copy from your Supabase)
  Click: Add

Variable 2:
  Name: SUPABASE_KEY
  Value: eyJhbGc... (long text)
  (Copy the anon public key from Supabase)
  Click: Add

Variable 3:
  Name: DOMAIN
  Value: https://shortlink-YOURNAME.vercel.app
  (Same as in index.html)
  Click: Add

Go to: Deployments tab
Click: three dots (...) on latest deployment

IF YOU GET STUCK:
═══════════════════════════════════════════════════════════════════════════════

Error: "SUPABASE_URL is missing"
  → Check Vercel environment variables are added
  → Redeploy after adding

Error: "Links not saving"
  → Did you create database table in Supabase? (DEPLOY_ONLY.md Step 3)
  → Did you add SUPABASE_KEY and SUPABASE_URL to Vercel?

Error: "Cannot connect to API"
  → Make sure API_URL in index.html matches your Vercel domain
  → Make sure it has "https://" at the start
